# QA Preview Only — Do Not Merge

This tree contains a compile-time QA-only bridge that permits the already isolated P1A service to be exercised before tri-platform completion. It is active only when built with `--dart-define=KRISTIN_QA_PREVIEW=true` and when the installed connector declares `qaPreview: true`. Formal completion remains false.
