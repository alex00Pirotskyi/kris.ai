# QA handoff record

Record for each platform:

- Artifact filename and SHA-256
- Source commit and source tree
- GitHub workflow run/attempt
- Operating system/build and architecture
- Tester and date
- Clean extraction/launch result
- P1/P1A native self-test result
- P2-001 through P2-014 results
- Crash/restart/uninstall result
- Unresolved issues and accepted risks

Do not remove the owner-risk banner or describe the artifact as production release eligible.
