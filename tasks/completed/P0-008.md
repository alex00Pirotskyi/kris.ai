# P0-008 — Create roadmap control files and bootstrap manifest

## Status

DONE after application; DONE only after complete-checkout validation and independent review.

## Objective

Create a dependency-free, machine-validated roadmap control plane for P0 and P1 so a new AI session can select the next ready task without oral context.

## Dependencies

- `P0-001`

## In scope

- `docs/roadmap/MASTER.md` human constitution marker and P0-008 amendment.
- `docs/roadmap/roadmap.yaml` P0/P1 machine authority.
- Generated `STATUS.md` and `HANDOFF.md`.
- Decision, risk, metric, release-gate, and prompt files.
- ADR-0000 accepted control-plane decision and ADR-0001–0006 proposed placeholders.
- P0/P1 task packets and evidence links.
- Dependency, duplicate, cycle, status, authority, packet, evidence, and derived-file validation.
- Verification and CI integration.

## Required implementation

1. Establish one human and one bootstrap machine authority.
2. Encode P0/P1 tasks, dependencies, statuses, packets, and evidence.
3. Generate STATUS and HANDOFF from the manifest.
4. Reject duplicate IDs, missing dependencies, cycles, invalid statuses, incomplete dependency transitions, missing packets/evidence, stale derived views, and competing authority.
5. Provide `validate`, `next`, `explain`, and `render --check` commands.
6. Add unit and repository integration tests.
7. Preserve P0-002 trust retirement and all cumulative milestones present in the target checkout.

## Required tests

- Unit mutations for duplicates, missing dependencies, cycles, status errors, authority conflict, path traversal, evidence, and deterministic rendering.
- Repository gate verifies every control file, schema, prompt, ADR, task packet, verification hook, CI hook, and source-manifest entry.
- A fresh-session command returns at least one READY task or a precise reason none is ready.
- A second dry run proposes zero source changes.

## Acceptance criteria

- [ ] A clean checkout passes `python3 tool/roadmap_control.py validate --project . --strict`.
- [ ] `python3 tool/roadmap_control.py next --project . --json` returns complete packets for READY work.
- [ ] CI rejects duplicate IDs, missing dependencies, cycles, invalid status, stale STATUS/HANDOFF, missing packet/evidence, and authority conflict.
- [ ] P0/P1 dependencies in the manifest match MASTER.md.
- [ ] Proposed ADRs are not represented as accepted implementation authority.
- [ ] P0-002 remains disabled if present.
- [ ] Independent review records PASS before DONE.
