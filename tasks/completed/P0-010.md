# P0-010 — Remove committed generated state

## Status

DONE

## Objective

Remove reproducible workstation output from source control, expand the shared generated-state policy, and make standard verification non-mutating with respect to source files.

## Dependencies

- `P0-001`

## In scope

- Extend `tool/source_tree_policy.py` for Python, Flutter, native, Node, Playwright, browser, automation-host, dataset, and generated-report state.
- Add one managed `.gitignore` block generated from the same policy.
- Remove tracked paths classified as generated state.
- Remove generated paths from `SOURCE_MANIFEST.sha256`.
- Add Git/source-manifest auditing and clean-check snapshots.
- Add behavioral, negative, and cumulative-integration tests.
- Update P0-009 baseline with an explicit before/after delta when present.
- Preserve P0-002 trust retirement and cumulative milestone files.

## Out of scope

- Removing reviewed generated Dart contracts.
- Deleting milestone evidence under `release/evidence/<task-id>/`.
- Replacing the release-evidence architecture.
- Git-history rewriting.
- Secret-scanning v2; that remains `P8-007`.
- Full release-pipeline redesign; that remains `P9-001` and `P9-002`.

## Required implementation

1. Install generated-state policy v2 and its canonical ignore block.
2. Remove every currently tracked path that policy v2 classifies as disposable.
3. Back up every removed path outside the repository before deletion.
4. Add a strict audit that uses the Git index in checkouts and the source manifest in archives.
5. Add snapshot/verify-clean commands that detect non-generated test drift.
6. Make `tool/verify.sh` formatting non-mutating when the legacy command is present.
7. Add the P0-010 gate to CI and verification.
8. Regenerate source-manifest hashes.
9. Regenerate and compare P0-009 baseline when present.
10. Record audit, removal, benchmark, command, and file-hash evidence.
