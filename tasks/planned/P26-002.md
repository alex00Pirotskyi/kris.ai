# P26-002 — Project discovery, profile model and durable run identity

**Status:** `BLOCKED`  
**Depends on:** `P26-001`  
**Authority:** `docs/roadmap/P26_VERIFICATION_CENTER.md`  
**Manifest:** `docs/roadmap/p26/manifest.v1.json`

## Objective

Create project-neutral discovery, profile resolution, optional `.prowork/verification/`
configuration and durable run, source and environment identity.

## Scope

Implement only after P26-001 is complete on the exact protected-main lineage. Opening a
project must not execute arbitrary project content.

## Deliverables

- Safe project discovery and profile model.
- Versioned, idempotent optional project configuration.
- Durable run identity bound to exact project, source, profile and environment.

## Acceptance

- Opening a project executes no arbitrary project content.
- Configuration upgrades preserve human-authored fields and are versioned and idempotent.
- Every run binds exact project, source, profile and environment identity.

## Evidence

Record argv, exact source and tree identity, environment identity, timestamps, result
state and bounded evidence references.

## Stop policy

Stop on dependency drift, source mismatch, unsafe discovery, scope escape, missing
identity, or any hidden execution during project opening.
