# P26-011 — Native-owner campaigns, permissions and environment blockers

**Status:** `BLOCKED`  
**Depends on:** `P26-003`  
**Authority:** `docs/roadmap/P26_VERIFICATION_CENTER.md`  
**Manifest:** `docs/roadmap/p26/manifest.v1.json`

## Objective

Run governed native-application verification on owner machines with exact platform,
hardware, application, permission and source identity.

## Scope

Implement only after P26-003. Native campaigns certify only the tested platform and
environment; unsupported platforms and unavailable capabilities remain explicit blockers.

## Deliverables

- Owner-machine native campaign adapter and environment probe.
- Permission request, denial and recovery reporting.
- Platform-scoped evidence bundle and exact application identity.

## Acceptance

- Evidence never claims support for an untested or unsupported platform.
- Every run records hardware, OS, application build, permissions and exact source identity.
- Missing environment and denied permission remain distinct non-passing blockers.

## Evidence

Record platform and hardware identity, OS/build, application artifact digest, permission
state, exact source identity, timestamps, bounded artifacts and result states.

## Stop policy

Stop on dependency drift, unsupported platform, environment mismatch, denied permission,
application/source mismatch, stale evidence or cross-platform overclaim.
