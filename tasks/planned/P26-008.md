# P26-008 — Web verification through P3 browser and headless HTTP fixtures

**Status:** `BLOCKED`  
**Depends on:** `P26-003`  
**Authority:** `docs/roadmap/P26_VERIFICATION_CENTER.md`  
**Manifest:** `docs/roadmap/p26/manifest.v1.json`

## Objective

Add governed web verification through P3 browser journeys and a deterministic,
network-bounded headless HTTP fixture adapter.

## Scope

Implement only after P26-003. Reuse P3 browser and permission boundaries; do not create
an ungoverned browser runtime or imply that fixture evidence certifies arbitrary live
websites.

## Deliverables

- P3 browser-plan adapter with exact journey, artifact and environment identity.
- Deterministic local HTTP fixture server and headless request evaluator.
- Explicit environment, permission, network and unsupported-capability blockers.

## Acceptance

- Browser absence or unsupported runtime produces `BLOCKED_ENVIRONMENT`.
- Permission denial produces `BLOCKED_PERMISSION` rather than PASS or generic FAIL.
- HTTP fixture evidence is source-bound and cannot certify unrelated live websites.

## Evidence

Record browser/runtime or fixture identity, exact source and environment identity,
request/journey steps, timestamps, bounded artifacts and criterion result states.

## Stop policy

Stop on dependency drift, browser/runtime substitution, unbounded network access,
permission bypass, source mismatch, stale artifact reuse or evidence overclaim.
