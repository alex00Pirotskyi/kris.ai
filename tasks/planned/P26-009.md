# P26-009 — Coverage ingestion and source mapping

**Status:** `BLOCKED`  
**Depends on:** `P26-003`  
**Authority:** `docs/roadmap/P26_VERIFICATION_CENTER.md`  
**Manifest:** `docs/roadmap/p26/manifest.v1.json`

## Objective

Import Cobertura XML, LCOV and native/source-map coverage, bind it to exact source, and
present truthful mapped, unmapped and unknown coverage.

## Scope

Implement only after P26-003. Coverage is supporting evidence, not a substitute for
acceptance execution, and absent or unmappable data must never become 100%.

## Deliverables

- Streaming or bounded parsers for the governed coverage formats.
- Deterministic path normalization and exact-source mapping.
- File, range, criterion and summary views that preserve unknowns.

## Acceptance

- Missing or source-unmappable coverage is `UNKNOWN`, never 100% or PASS.
- Malformed, stale or cross-source input fails closed with an explicit explanation.
- A 10 MiB governed fixture parses within the performance budget without unbounded memory growth.

## Evidence

Record coverage format and digest, producer identity, exact source mapping identity,
parse timings, mapped/unmapped counts, warnings and result state.

## Stop policy

Stop on dependency drift, stale or cross-source evidence, path escape, parser resource
violation, silent record loss, unknown coercion or summary overclaim.
