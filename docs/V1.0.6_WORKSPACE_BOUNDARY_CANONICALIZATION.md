# Kristin Local Agent v1.0.6+106 workspace-boundary canonicalization merge

This release forward-ports the user-supplied Windows workspace-boundary patch onto v1.0.5+105. It is the canonical source baseline after the merge.

## Problem fixed

Windows `Directory.resolveSymbolicLinks()` can return an extended-length canonical path such as `\\?\C:\project` or `\\?\UNC\server\share`. A model or filesystem listing normally supplies the equivalent plain absolute path. Comparing those representations without normalizing the prefix can falsely report `path_outside_project` even though the target is inside the selected project.

`WorkspaceBoundary._normalizeAbsolute` now converts extended drive and UNC forms to their plain equivalents before case-normalized project-boundary comparison. The existing v1.0.5 bounded compatibility rebasing remains available for stale or virtual workspace paths; the new normalization handles genuine in-project paths before heuristic recovery is considered.

## Regression coverage

A Windows-gated Flutter test opens a temporary project through a filesystem link and verifies that a plain absolute path to the resolved target normalizes to `lib/main.dart`. Existing tests continue to require outside paths, traversal, secret-like recovery paths, and arbitrary external writes to remain blocked.
