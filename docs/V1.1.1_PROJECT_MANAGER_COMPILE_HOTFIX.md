# Kristin Local Agent v1.1.1+111 Project Manager compile hotfix

## Reported Windows failure

The v1.1.0 workstation run completed formatting and dependency resolution, then Flutter analysis stopped at `lib/product/project_diagnostics.dart:303` because `ProjectDiagnosticsService` referenced `ProductException` without importing the library that defines it. Flutter tests failed during compilation for the same reason.

## Repair

`project_diagnostics.dart` now imports:

```dart
import 'storage_security.dart';
```

`ProductException` remains defined once in `storage_security.dart`; the hotfix does not duplicate or move the exception type. Project Manager behavior, project command profiles, process controls, tool permissions, and project-boundary enforcement are unchanged.

## Regression gates

The release now fails deterministic validation when any of these conditions is absent:

- `project_diagnostics.dart` explicitly imports `storage_security.dart`.
- `storage_security.dart` defines `ProductException`.
- `project_diagnostics.dart` contains the guarded `throw ProductException(...)` path.
- The structured release lineage retains v1.1.0+110 as the immediate parent.
