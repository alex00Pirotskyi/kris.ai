# Kristin Local Agent v1.1.3+113 workstation validation hotfix

## Reported workstation failures

The supplied v1.1.2 Windows transcript showed that formatting and dependency resolution completed, but authoritative validation stopped on three independent defects:

1. `models_research.dart` declared an optional `_HttpCancellationBinding.subscription` constructor parameter that no call site supplied, producing `unused_element_parameter` under fatal analyzer infos.
2. `source_contract_test.dart` searched for the formatter-sensitive literal `stage: 'load_started'`, although the production code correctly chose between `load_started` and `load_retry_started` with a conditional expression.
3. `v1_product_preview_test.dart` required the exact sentence fragment `Do not claim a public URL`, while the production instruction expressed the same rule as `Do not deploy ... or claim a public URL`.

The system and release commands therefore reached the native Flutter gates successfully but stopped at analysis or tests.

## Corrections

V1.1.3 removes the unused constructor parameter while retaining explicit subscription cancellation. The cold-load regression now verifies the complete progress sequence behaviorally:

```text
load_started
load_retry_scheduled
load_retry_started
load_completed
generation_started
```

The source contract checks stage tokens rather than formatter-dependent adjacency. Local-only deployment normalization now emits two explicit sentences:

```text
Do not deploy to an external service.
Do not claim a public URL.
```

Offline system and release validators independently reject reintroduction of the unused parameter, the brittle source assertion, or the ambiguous deployment wording.

## Upgrade behavior

No application-data migration is required. Extract the new source release into a clean directory. Registered projects, prompts, plans, knowledge, diagnostics, and run history remain in the separate application-data root.
