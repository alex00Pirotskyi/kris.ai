# v0.9.2+92 Windows compile and knowledge API hotfix

This hotfix responds to a clean Flutter 3.44.0 / Dart 3.12.0 Windows analysis and test run of v0.9.1+91.

## Reported blockers

- `project_diagnostics.dart` still used the unsupported inline `(?m)` regular-expression flag.
- The same file retained two unused imports.
- `knowledge_memory_test.dart` called `KnowledgeService.list(projectId)`, but the service did not expose that method.

## Repairs

- The Flutter-project detector now uses `RegExp(r'^flutter:\s*$', multiLine: true)`.
- Unused project-diagnostics imports were removed.
- `KnowledgeService.list(projectId)` now returns only the selected project's entries, newest first, with deterministic ID ordering for equal timestamps.
- `ProductRuntime.listKnowledge` delegates to the same service method.
- A behavioral regression test verifies project scoping and ordering.
- The source contract and offline release validator now fail if inline RegExp flags return or if the service/test API drifts again.
