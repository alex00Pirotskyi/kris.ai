# Kristin v1.5.1+151 — Linux sandbox backfill on the real source line

This cumulative source head keeps the verified v1.3 durable workflow kernel and the v1.5 Prompt Studio 2 plan compiler, then backfills the missing operating-system execution boundary that the roadmap places before later project-operation and convergence work.

Implemented in this source head:

- Linux namespace sandbox worker using unprivileged user, mount, PID, and network namespaces;
- read-only and snapshot-writable workspace modes;
- bounded finite-command execution for CLI project commands;
- HTTPS-only public network broker with host allowlist and private-address rejection;
- one-use secret broker for approved sandbox environment injection;
- sandbox-aware CLI routing for Analyze, Test, Build, Run, and internal source gates;
- trusted host mode for sandbox self-tests so nested user-namespace restrictions do not create false negatives;
- Linux parent-death signaling and `unshare --kill-child` so a worker launcher crash cannot strand the PID-namespace command;
- PID-reuse-safe process identities and bounded complete-tree termination for managed cancellation;
- source and release validation hooks for the worker and brokers.

The cancellation boundary is layered. Project Manager records the launcher's
Linux start-time ticks, snapshots the complete descendant tree before sending a
signal, refuses to signal a recycled PID, and verifies that no captured
descendant remains. The worker also requests a kernel parent-death signal, and
the namespace launcher kills its namespace child when it exits. A failed
cleanup is persisted as `process_tree_termination_incomplete` rather than being
reported as a successful Stop.

Not claimed by this release:

- native Windows isolated worker backend;
- native macOS isolated worker backend;
- full cross-platform v1.4 exit-gate completion;
- sandboxed MCP and file-format adapters;
- preview-port publication or general worker networking.

This is therefore a cumulative **sandbox backfill** on top of v1.5, not a claim that the entire roadmap v1.4 milestone is finished on every platform.
