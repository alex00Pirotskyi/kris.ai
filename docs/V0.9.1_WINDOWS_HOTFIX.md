# v0.9.1+91 Windows startup and analyzer hotfix

This hotfix responds to a Flutter 3.44.0 / Dart 3.12.0 Windows verification run of v0.9.0+90.

## Correct PowerShell commands

```powershell
.\kristin.cmd doctor --project .
.\kristin.cmd test --quick --project .
.\kristin.cmd test --full --project .
.\RUN_WINDOWS.bat
```

PowerShell does not search the current directory when a bare command name is entered. The `.\` prefix is therefore required unless the project directory has been added to `PATH`.

`--project` now also accepts no value and treats it as the current directory:

```powershell
.\kristin.cmd doctor --project
```
