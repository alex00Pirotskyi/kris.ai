# V1.9.0 — Interoperability, Administration, and Release Operations

This source release adds a typed interoperability and administration layer on top of the cumulative v1.8 foundation.

## Implemented source capabilities

- signed/authenticated manifest envelopes for plugin, agent, skill, update, and audit checkpoint material;
- sandboxed local MCP lifecycle bridge for initialize, tools, resources, and prompts;
- bounded A2A task delegation with capability, artifact, and step-budget enforcement;
- policy profiles and fleet configuration overlays;
- append-only audit-chain verification and checkpoint authentication;
- authenticated update manifest verification and rollback planning;
- support lifecycle and compatibility policy primitives;
- SQLite migration 006 for manifests, policies, audit checkpoints, release updates, and delegated-agent records.

## Honest boundary

This source release does not claim completed native installer signing, remote A2A networking, or production-grade cross-platform transport backends. It provides the deterministic policy, manifest, verification, and sandboxed local execution foundation required by the roadmap.
