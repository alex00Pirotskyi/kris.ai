# P1 trust, policy and core-architecture closure

P1 is closed only when P1-001 through P1-012 are `DONE`, all task evidence exists, the P1 exit gate passes, branch and protected-main CI are green on Windows/macOS/Linux, and the aggregate manifest is committed.

The closure establishes one access-policy model, authenticated capability grants, Signed Manifest v2 with external trust roots, v1 downgrade rejection, TUF trust design, protected key references and revocation, signed audit checkpoints, threat-model ownership and authenticated local IPC.
