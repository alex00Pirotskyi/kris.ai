# P4 phase completion candidate

This branch is the reconciled P4-002 through P4-022 implementation candidate on top of the landed P4-001 provider contract and the landed P3 browser/Web Studio phase.

The four P4 research product libraries are registered in the governed Dart source inventory. The root source manifest is regenerated from the reconciled candidate before final validation so the manifest, source contract, and active product tree describe the same commit state.

Implemented source surfaces include bounded query planning and ranking, connection-time pinned HTTPS fetching, rendered-fetch adaptation, readable and structured extraction, robots-aware resumable crawling, immutable citations and content-addressed evidence, replaceable lexical/semantic indexing, authority migrations, dataset versioning/transforms/exports, freshness/change monitoring, Research and Data workspaces, a machine-scored quality corpus, and the operator guide.

This checkpoint records implementation and validation state only. It does not claim roadmap acceptance, release support, production support, or GA promotion; those remain separately gated by full repository evidence and acceptance/promotion controls.
