## Authority boundary

Until a reviewed adoption PR explicitly changes repository authority:

1. `docs/roadmap/MASTER.md` remains the human implementation authority.
2. `docs/roadmap/roadmap.yaml` remains the machine authority for its declared scope.
3. ANARCHY is a proposed execution overlay and worker-memory system.
4. ANARCHY files may organize work, but may not silently relabel incomplete roadmap tasks as complete.

## Dream command

```text
Take https://github.com/alex00Pirotskyi/kris.ai.
You are Worker F. Continue.
```

That sentence is intended to be enough. The worker reads its own repository memory, resolves live Git state, continues the active task, verifies, documents, commits, pushes, and leaves the next worker-readable state.
